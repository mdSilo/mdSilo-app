# Write and find a note

## Create a note
Verify the "Welcome" note is shown with "Hello, welcome to mdSilo."
In the narrow icon bar on the far left, click the green feather icon just below the orange RSS icon (its tooltip is "New Writing").
Verify a "new or find" box appears.
Type "Reading List" in the "new or find" box and press Enter.
Verify the "Reading List" note is open and listed in the sidebar above "Welcome".

## Write in it
Click the "Markdown editor" text box below the "Reading List" title and type "Books to read this year #reading".
Verify the note shows "Books to read this year" and the "#reading" tag.

## Find it again
Click the "#" tab at the top of the sidebar.
Verify the "reading" tag is listed.
Click the "Welcome" note in the files tab, then click the magnifier tab at the top of the sidebar.
Type "Books to read" in the search box.
Verify "Reading List" is shown in the search results.
