# Welcome to mdSilo

**A hub for your personal I/O: Reading (input) → Issue (process) → Writing (output).** #manual#

mdSilo keeps everything you read, think and write in one local workspace of plain files. You are looking at its manual, and this manual is itself a set of notes in your workspace: click around, edit anything, break anything. It is yours.

## A five minute tour

1. **Read.** Open the Library (the books icon in the side menu) and open *Alice's Adventures in Wonderland*. Select a sentence and highlight it. Your highlight is saved as a note next to the book.
2. **Think.** From the highlight, choose *New issue of it*. The sentence becomes an issue you can label, schedule and move across a project board.
3. **Write.** Open a new note with `Ctrl/Cmd + N`, type `[[` to link to another note, `{{` to link to a book or a highlight, and `/` for everything else.
4. **See.** Press `Ctrl/Cmd + Shift + G` for the Graph: notes, books and issues, tied together by the links you made.

:::info
**Mac users**: read `Ctrl` as `⌘ Cmd`. All shortcuts use the `mod` key, which is `Ctrl` on Windows and Linux and `⌘` on macOS.
:::
