# 链接

#手册#

链接把一堆文件变成知识库，也把阅读、issue 和写作连在一起。mdSilo 里所有链接都是**双向**的：A 链接到 B，B 就能看到 A。

## Wiki 链接

输入 `[[`，开始键入笔记标题，从列表里选一个。如果不存在，选 *Create a new doc*。带别名的链接写作 `[[理念|为什么这样设计]]`。

试试看：这里有一条链到 [[1 理念|理念]]，还有一条链回 [[0 开始|开始页]]。

重命名或移动笔记时，指向它的链接会跟着更新。

## 反向链接

滚到笔记底部，展开 **BackLinks**：能看到所有链接到这里的笔记，以及链接周围的句子。打开这篇和 [[1 理念|理念]] 的反向链接，就能看到手册里有哪些章节指向它们。

提到了本篇标题、但没有加链接的笔记，会作为未链接的提及列出来，点一下就能补上链接。

## 标签

在笔记里随处写 `#idea#`（两侧各一个 #）。侧栏的 **Hashtag** 页列出所有标签，点一个就列出带这个标签的笔记。这整套手册都带有 #手册# 标签。

特殊标签 `#todo#`、`#doing#`、`#done#` 表示任务，见 [[7 Issue|Issue]]。

## 链接到书和高亮

输入 `{{` 搜索你的书库：先按书名或作者，再按你的高亮引文和笔记。选一本书，得到类似 {{Alice's Adventures in Wonderland}} 的链接；选一处高亮，链接会**直接打开书并定位到那句话**。

- 点这样的链接，书会在阅读器里打开。
- 手写的 `{{书名}}` 和 `{{书名|别名}}` 也可以。
- 在书这一侧，阅读器的 **Links** 页列出所有指向这本书的笔记和 issue。
- 在阅读器里，选区上方的工具栏可以复制**带回链的引文**，直接粘贴到笔记里。

## 链接到 issue

写 `[@12](issue:12)` 链接 12 号 issue，或者输入 `[[` 后从列表里选一个 issue。如果 issue 也指回这篇笔记，笔记底部会显示 **Referenced by issues**。在 issue 里，`[[笔记标题]]` 链接一篇笔记，issue 侧栏会列出它链接的笔记和书。见 [[7 Issue|Issue]]。

## 链接类型一览

| 你输入 | 链接到 | 点击打开 |
|--------|--------|----------|
| `[[笔记]]` | 一篇笔记 | 这篇笔记 |
| `[[笔记\|别名]]` | 一篇笔记，显示为别名 | 这篇笔记 |
| `{{书名}}` | 一本书 | 阅读器里的这本书 |
| `{{书名\|别名}}` | 一本书 | 这本书 |
| `[@12](issue:12)` | 12 号 issue | 这个 issue |
| `[文字](https://...)` | 网页 | 你的浏览器 |
| `#标签#` | 一个标签 | 带这个标签的笔记 |

## 看见链接

整个工作区的链接都画在 Graph 里：笔记、书、issue，以及它们之间的连线。见 [[8 洞察|洞察]]。索引是增量的，几万篇笔记的工作区也很快。
