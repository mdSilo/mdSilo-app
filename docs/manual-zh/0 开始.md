# 欢迎使用 mdSilo

**个人输入/输出的中枢：阅读（输入）→ 议题Issue（处理）→ 写作（输出）。** #手册#

mdSilo 把你读的、想的、写的放在同一个本地工作区里，全部是纯文本文件。你现在看到的这套手册，本身就是工作区里的一组笔记：随便点，随便改，改坏了也没关系，它是你的。

## 五分钟上手

1. **读。** 点侧边菜单的书架图标打开 Library，打开 *Alice's Adventures in Wonderland*。选中一句话，高亮它。高亮会作为笔记保存在书的旁边。
2. **想。** 对着高亮选择 *New issue of it*，这句话就成了一个 issue，可以加标签、定期限，在项目看板上拖动。
3. **写。** 按 `Ctrl/Cmd + N` 新建笔记；输入 `[[` 链接别的笔记，`{{` 链接书和高亮，`/` 调出其它一切。
4. **看。** 按 `Ctrl/Cmd + Shift + G` 打开 Graph：笔记、书、issue，你建立的链接会连成一张网。

:::info
**Mac 用户**：把 `Ctrl` 读作 `⌘ Cmd`。所有快捷键用的是 `mod` 键，Windows 和 Linux 上是 `Ctrl`，macOS 上是 `⌘`。
:::

## 给你的任务

下面两行是真正的任务，它们会出现在 Issues 视图的 **Tasks** 页，可以一键变成完整的 issue。

- [ ] 在 Alice's Adventures in Wonderland 里高亮一句话
- [ ] 在手册和你自己的笔记之间建立一条链接
