# 工作区

#手册#

**工作区**就是一个文件夹。mdSilo 在侧栏里显示其内容、为其建立索引，并把自己创建的一切都放在里面。

## 目录结构

```
my-workspace/
├── reading/        书、书的批注（Foo.epub.md）、剪藏
├── writing/        笔记及附件、日记
└── .mdsilo/        数据：books.json、issue、feeds.json、生词本
    └── local/      只属于这台设备，不同步：搜索索引、缓存
```

- **writing/** 放你的笔记。笔记是一个 Markdown 文件，标题就是文件名。文件夹可以任意嵌套。
- **reading/** 放你读的书，以及每本书旁边的批注文件（`Foo.epub` → `Foo.epub.md`）。剪藏的网页文章在 `reading/clips/`。
- **.mdsilo/** 放沉淀出的内容：书库、阅读进度、issue、订阅。全部是纯 JSON。

因为一切都是文件，整个工作区可以用 git、Dropbox 或别的方式同步。桌面版自带 git 同步，还能把选定的笔记发布成网站，见 [[9 同步与发布|同步与发布]]。书籍默认不同步（因为涉及版权原因），需要你逐本选择（见 [[5 阅读器|阅读器]]）。`local/` 文件夹会被自动排除。

:::tip
打开一个空文件夹，它自己就成为工作区。已经有 Markdown 文件的文件夹会按原样打开（*legacy* 工作区），侧栏里会提供 **Upgrade**，迁移到这个结构。
:::

## 侧栏

侧栏有四个标签页：

- **Silo**（`Ctrl/Cmd + Shift + D`）：文件树。用条目上的 `…` 菜单新建、重命名、移动、删除。用排序按钮给文件树排序。
- **Search**（`Ctrl/Cmd + Shift + F`）：对笔记、批注和书的正文做全文搜索。见 [[参考]]。
- **Hashtag**（`Ctrl/Cmd + Shift + H`）：工作区里所有的 `#标签#`，点一个就列出带它的笔记。见 [[4 链接|链接]]。
- **Playlist**（`Ctrl/Cmd + Shift + P`）：你的播客频道里的所有节目。

侧栏顶部的数字是笔记数。下面的 **Reading** 和 **Writing** 是文件树的两个根。

## 新建和打开

- `Ctrl/Cmd + N` 打开“查找或新建”：输入来搜索笔记，对还不存在的名字按回车就新建。
- 用侧边菜单底部的文件夹图标打开其它文件夹或 Markdown 文件。
- 启动时会重新打开上次的文件夹。在设置里可以改成固定文件夹、不打开，以及选择先显示具体视图。
