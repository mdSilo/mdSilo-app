## 快捷键

`Mod` 在 Windows 和 Linux 上是 `Ctrl`，在 macOS 上是 `⌘`。

### 应用

| 快捷键 | 操作 |
|--------|------|
| `Mod + N` | 查找或新建笔记 |
| `Alt + X` | 显示或隐藏侧栏 |
| `Mod + Shift + D` | 侧栏：Silo（文件树） |
| `Mod + Shift + F` | 侧栏：Search |
| `Mod + Shift + H` | 侧栏：Hashtag |
| `Mod + Shift + P` | 侧栏：Playlist |
| `Mod + Shift + R` | 视图：订阅 |
| `Mod + Shift + L` | 视图：Library |
| `Mod + Shift + I` | 视图：Issues |
| `Mod + Shift + T` | 视图：Tasks |
| `Mod + Shift + K` | 视图：Projects |
| `Mod + Shift + C` | 视图：Chronicle |
| `Mod + Shift + G` | 视图：Graph |

### 编辑器

| 快捷键 | 操作 |
|--------|------|
| `Mod + B` / `I` / `U` | 加粗 / 斜体 / 下划线 |
| `Mod + D` | 删除线 |
| `Mod + H` | 高亮 |
| `Mod + 反引号` | 行内代码 |
| `Mod + K` | 链接 |
| `Mod + Shift + Space` | 插入表格 |
| `/` | 斜杠命令菜单 |
| `[[` | 链接笔记或 issue |
| `{{` | 链接书或高亮 |
| `#标签#` | 标签 |
| `Ctrl + 1` / `2` / `3` | 标题 |
| `Ctrl + 7` / `8` / `9` | 任务、无序、有序列表 |

## 搜索

侧栏的 **Search** 页对工作区做全文搜索：笔记、书的批注，以及你打开过的书的正文。结果会显示词出现的位置。索引在后台建立，编辑时增量更新；中文等不用空格分词的语言会按词切分。

## 设置

侧边菜单底部的齿轮打开全局设置：

- **Theme**：mdSilo 亮色和暗色，或跟随系统，另有八个内置主题。
- **Side menu orientation**：竖排或横排。
- **Open on startup**：上次的文件夹、固定的文件夹或不打开；以及 **view on startup**。

各个区域的设置放在用到它的地方：编辑器的在笔记的齿轮里（字体、字号、拼写检查、附件文件夹），阅读器的在顶栏的 *Font and layout*，订阅的在 *Manage Channels and Settings*。

## 网页版

和这套手册在同一个地址的网页版，就是同一个应用。区别：

- 你的工作区**存在浏览器里**（IndexedDB），不会发送给任何服务器。
- 用 **Open Folder** 从设备导入文件夹，用笔记的选项菜单导出；文件由浏览器下载。
- 订阅要走 CORS 代理，见 [[6 订阅|订阅]]。
- 没有原生的文件监听和 git；书很多的话，[桌面版](https://github.com/mdSilo/mdSilo-app/releases)更合适。

:::warning
**请备份。** 清除浏览器的站点数据会删掉你的笔记。用 **File Menu**（侧边菜单底部的文件夹图标）> **Backup** 把全部内容下载为 zip。恢复时解压，再用 *Open Folder* 导入那个文件夹。
:::

:::info
**清除示例。** 网页版首次打开时附带的手册、示例书和示例 issue，可以用 **File Menu**（侧边菜单底部的文件夹图标）里的 **Remove demo** 一键删除。你自己建的笔记、issue 和书不受影响。
:::

## 桌面版

支持 Windows、macOS 和 Linux。你的工作区就是真实的文件夹：可以用 git、Dropbox、Syncthing 同步，也可以用别的编辑器改文件，改动会出现在 mdSilo 里。

## 永远是纯文件

| 内容 | 位置 | 格式 |
|------|------|------|
| 笔记 | `writing/**/*.md` | Markdown |
| 书的批注 | `reading/Foo.epub.md` | 带注释的 Markdown |
| 剪藏的文章 | `reading/clips/*.md` | Markdown |
| 书库 | `.mdsilo/books.json` | JSON |
| 阅读进度 | `.mdsilo/books/<id>.json` | JSON |
| Issue、标签、项目 | `.mdsilo/` | JSON |
| 订阅 | `.mdsilo/feeds.json` | JSON |
| 生词本 | `.mdsilo/vocabulary.json` | JSON |
