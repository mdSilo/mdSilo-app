# 阅读器

#手册#

阅读器是 mdSilo 的输入端。支持阅读、标注，并把标注保存为普通笔记，汇入你其余的知识库。

支持的格式：**EPUB、PDF、MOBI、AZW/AZW3、FB2、CBZ**（漫画）。TXT、Markdown、HTML 和 ZIP 文件在导入时会转换成 EPUB，你的原文件不会被改动。

## Library

用侧边菜单的书架图标打开（`Ctrl/Cmd + Shift + L`），列出工作区里所有的书。

- **Add books**：把书文件拖进窗口，或用 *Import*。网页版里书存在浏览器中；桌面版会复制到 `reading/`。
- **Add folder**：导入一个文件夹及其子文件夹里的所有书，可以选格式。
- **网格或列表**：网格显示封面，列表显示作者、丛书和简介。
- **搜索**支持纯文本和正则，匹配书名、作者、格式、分组、状态、丛书、主题和简介。
- **分组**：把一本书拖到另一本书上建组，拖到组上移进去，拖到面包屑上移到上一层。分组可以嵌套（`Fiction/Classics`）。也可以按作者、丛书、格式或状态分组。
- **状态**：给书标 *Todo*、*Doing*、*Done*，或你自己的标记。
- **详情**：编辑元数据（书名、作者、丛书、语言……）、设置分组和状态、给文件改名、复制指向它的链接、打开它的批注。

书是按内容识别的（部分 MD5 哈希），所以改名或移动过的书，在每台设备上仍是同一本书。它的笔记（`Foo.epub.md`）会跟着它走，不管是在应用里、侧栏里还是在文件管理器里改名。

:::info
**同步，逐本选择。** 书可能很大，所以默认*不*随 git 同步。每本书、每个分组都有同步开关；批注和阅读进度总是同步的。见 [[9 同步与发布|同步与发布]]。
:::

## 阅读

打开一本书，页面占满窗口。鼠标移到上下边缘，或点击页面中间，就会出现工具栏。

- **翻页**：点页面左侧或右侧，用方向键、鼠标滚轮，或底部的滑块。点中间显示或隐藏工具栏。
- **顶栏**：回到 Library、目录和笔记、书签、并排阅读、*Font and layout*。
- **回到书里**：在某个工作区读过书之后，侧边菜单会出现一个打开的书的按钮（`Ctrl/Cmd + Shift + B`），回到上次读到的那一页。在设置里把 *View on Startup* 设为 *Last Book*，mdSilo 启动时就打开它。
- **在单独的窗口里读**（桌面版）：在 Library 的视图菜单里选 *Open books in* → *A new window*；或在书的详情里点 *Read in a new window*。这个窗口只有阅读器：笔记、issue 和 Library 在主窗口里打开。再次打开这本书会把它的窗口调到前面。
- **底栏**：阅读历史的后退和前进、上一章和下一章、进度滑块，以及全书剩余时间。
- **目录和笔记**（侧面板）：目录、你的批注、书内搜索，以及 **Links** 页。
- **字体和布局**（数值用 − 和 + 调）：字体、CJK 字体（字体里没有的中日韩文字用它；字体选「Of the book」时，用于书没指定字体的地方）、字号、间距、书写方向、栏数、宽度、页边距、页面颜色（跟随应用、白、米黄、灰、深色）、翻页或滚动、动画、页眉页脚显示什么、点页面两侧翻页（或点左侧向后翻）、图片选项、代码高亮、阅读标尺、word lens 和翻译。
- 点击页面里的**图片**或**表格**可以放大查看。脚注会在小弹窗里打开，而不是跳走。
- **阅读标尺**（在 *Font and layout* 里）：盖住一到六行的一条横带，帮你盯住读到的地方。把它拖到正在读的位置；翻页的按键先让它按行往下移，移过最后几行才翻页。它的颜色给带里的文字着色（选无色则只描出边框），透明度可调。
- 你读到哪里、读了多久，都按书保存，并汇入 [[8 洞察|洞察]] 里的热力图。

### 书写方向：竖排的书

中文、日文、韩文的书常常是竖排的。*Font and layout* 里的 *Writing Mode* 设置当前这本书的方向（每本书各自记住）：*As the book*（按书里写的）、*Horizontal*（横排）、*Vertical, right to left*（竖排，从右往左读，像传统的中文书）、*Vertical, left to right*（竖排，从左往右），或 *Horizontal, right to left*（横排，从右往左）。从右往左写的书，往左是向后翻。*Double border* 给竖排的页面加上旧式刻本那样的双线边框。把 *Width* 调到最大，一行就能占满整页的高度。

拿一本中文小说的 TXT 试试：拖进 Library，它会转成 EPUB，按标题（第一回、第一章、Chapter 1……）分好章节；打开它，选 *Vertical, right to left*。

### 漫画和 PDF

页面固定的书（PDF、CBZ 漫画、固定版式的 EPUB）有自己的 *Font and layout*：

- **Layout**：*Pages*（翻页），或卷轴式地 *Vertical*（竖向）、*Horizontal*（横向）滚动。
- **Zoom**：用 − 和 + 缩放（或 `Ctrl/Cmd -`、`Ctrl/Cmd +`，`Ctrl/Cmd 0` 复原）；**Fit**：适合整页或宽度。
- **Spread**：单页，或两页并排；*Cover page alone* 让封面单独一页，配对和纸书一样。
- **Webtoon (no gaps)**：页与页之间没有空隙的竖向长条，占满宽度。
- **Lock horizontal panning**：放大的页面只能上下移动。
- **Right-to-left pages**：从右往左翻，用于漫画（CBZ 里写不了这一点）；按书记住。

## 高亮和笔记

选中文字，上方会出现工具栏：

| 操作 | 作用 |
|------|------|
| Copy | 复制文字 |
| Highlight | 标记文字；可选样式（高亮、下划线、波浪线）和颜色 |
| Note | 给高亮写一条 Markdown 笔记 |
| Search | 在书里搜索选中的内容 |
| Dictionary | 查词（最多六个词），用你的词典，Wikipedia 也是其中之一；可听发音、加入生词本 |
| Translate | 翻译成设置里选定的语言 |
| Read aloud | 从选区开始朗读 |
| Copy quote | 把文字复制成 Markdown 引文，带回到这一页的链接 |
| Copy link | 指向书中这个位置的链接 |
| **New issue of it** | 用选中内容建一个 issue，见 [[7 Issue|Issue]] |

你所有的标注都写进**书旁边的一个 Markdown 文件**：`Foo.epub` 对应 `Foo.epub.md`。它是一篇普通笔记：每章一个标题，每条高亮是一段引文，你的笔记写在下面。你可以编辑它、搜索它、用 `[[ ]]` 链接它，也能在 Graph 里看到它。

```markdown
## Chapter I

<!-- mdsilo:note {"id":"…","cfi":"epubcfi(…)","color":"yellow"} -->
> Alice was beginning to get very tired of sitting by her sister on the bank

开篇。整本书是一场关于好奇心的梦。
```

注释里记着位置，这样高亮才能重新画回页面上；编辑器会原样保留它。点页面上的高亮，会显示它的笔记和链接到它的 issue。

- **调整范围**：选区和点开的高亮两端各有一个手柄，拖动它们可以多选或少选一些文字。
- **笔记不挡字**：带笔记的高亮在它那一行旁边有个小小的笔记标记；指向或点击这个标记，才显示笔记。

## 从书走向工作区的其余部分

- 在任何笔记里用 `{{` **链接到书**。链接到某处高亮，就能跳到那句话。见 [[4 链接|链接]]。
- 侧面板的 **Links** 页列出指向这本书的笔记和 issue：它的反向链接。
- **New issue of it**：引文和回链变成一个 issue。批注列表里每条高亮都有同样的按钮。
- Graph 把书画成一个节点，连着它的批注笔记，以及每篇链接它的笔记。

拿 {{Alice's Adventures in Wonderland}} 试一试：它在你的 Library 里，第一章已经有一处高亮。加上你自己的高亮，把它做成 issue，再去看 Graph。

## 并排阅读

顶栏的 *Parallel reading* 会在右侧打开第二本书。两本书可以独自翻页，都可以高亮和写笔记。用它来对照译本和原文，或正文和注疏。同一本书不能在两栏同时打开。拖动两栏之间的线可以调整宽度（双击恢复各占一半）；宽度会记住，书和笔记都一样。

**边读边写。** 同一菜单的 *Write beside* 页签在这一栏打开一篇笔记：最近写过的、按标题找到的，或新建一篇。然后：

- 把书页里选中的文字拖进笔记：成为一段引文，附指回原处的链接，落在放下处那一段的下面；
- 或者点选区工具栏（或高亮上）的 *Quote in the note beside*：引文放在笔记光标所在段落的下面，光标停在引文后，接着写评论；
- *Notes* 列表里的批注也可以拖进笔记。

书自己的笔记文件（`Foo.epub.md`）不在可选之列：每次高亮阅读器都会重写它。栏头的箭头（*Swap sides*）把笔记或第二本书换到左边。在笔记里，右上角的 *Open beside*（两栏图标）有 *Read beside* 页签：打开一本书，这篇笔记在书旁边。*Close the book, keep writing*（在笔记栏头，或阅读器顶栏）关掉书，只留笔记。手机上没有。

## 词典、生词本和翻译

双击一个词，或选 *Dictionary*。弹窗里每个开着的词典一个页签，按你排的顺序，先显示第一个查到这个词的。词典有录音时，喇叭按钮可以播放（UK、US……）；放不了的声音会说明原因。

词典在 **Settings → Dictionaries**（或弹窗里的齿轮）里设置：逐个开关，拖动排序。

| 词典 | |
|---|---|
| Wiktionary | 大多数语言，书的语言优先；很多词有录音。默认开 |
| Wikipedia | 条目的摘要，用书的语言；没有条目时给出搜索链接。默认开 |
| Urban Dictionary | 英语俚语 |
| Merriam-Webster | 打开它的网站；填了你的 API key（dictionaryapi.com，非商业用途免费）后在弹窗里查，带录音 |
| Google | 打开 Google 的释义 |
| 你加的网站 | 任何网上的词典：一个用 `%WORD%` 代替词的网址；在浏览器里打开。可选填 API key（和网址分开存放、不显示），网址里用 `%KEY%` 代替它；网站的回答和 Merriam-Webster 的接口格式一样时（如 dictionaryapi.com 上它的 Learner's、Medical 词典：`https://www.dictionaryapi.com/api/v3/references/learners/json/%WORD%?key=%KEY%`）在弹窗里查，否则打开链接 |
| 词典文件 | MDict（`.mdx`，连同放图片和声音的 `.mdd`，以及 `.css`），用 **Import** 导入；导入后排在最前 |

词典文件放在工作区里（`.mdsilo/dictionaries/`），默认**不同步**（它们往往很大），要同步就点这本词典的云按钮。别的设备会把它标成 *Not here*，直到文件同步过去。词条里指向别的词条的链接会查那个词（箭头返回），喇叭按钮播放词典里的声音。暗色主题下，词典文件给词条定的颜色（为白底设计）看不清的地方会调亮。

**Add to vocabulary** 会把这个词连同释义、发音、来自哪本词典、所在的句子和指向书的链接存起来（存的时候没有发音的词，下次在有发音的词典里查到时会补上）。**Vocabulary** 页（在 Library 页头）可以用卡片、网格或批量方式复习；卡片正反面都有喇叭按钮，**P** 键播放当前这张。

**Word lens**（在 *Font and layout* 里）：书里遇到生词本里的词，会在词下面显示一个简短的释义——词形变化也算（*rabbits*、*taking*），还有短语（*take after*）和中日韩的词。点释义可以查这个词。释义取自存下的定义；选 *Gloss: Translation* 时是把词翻译成你选的翻译语言（存进生词本，只译一次）。也可以在生词卡片背面自己写。*Gloss size*（相对正文）和 *Gloss color*（页面的强调色、灰色或几种颜色，暗页上更浅）设置样式；行与行之间会按释义的大小在你的行高上留出空间。固定版式（PDF、漫画）不做。

**翻译。** 对选区点 *Translate*，会把它译成你选的语言（*Font and layout* 里的 *Translate to*）；弹窗里可以换翻译服务和目标语言。要整本书读译文，在 *Font and layout* 里打开 *Translate the book*：读到哪页译到哪页，译文放在每段下面，选 *Translation only* 则替换原文。译文会存下来，再读同一页不会再发一次。*Make the translated book…* 把其余部分也译出来（慢，一次几段；随时可以停，已译的都保留），在书旁边存一本 EPUB，放进 Library：`Foo.epub` 生成 `Foo.fr.epub`。

## 朗读

*Read aloud* 按钮会从选择的文字处或当前页开始朗读，逐句高亮，并自动进入下一章。控制都在播放器里（侧边菜单的耳机图标）：暂停、上一段/下一段、语速、引擎和声音。可选的声音是书的语言的那些。

引擎：

| 引擎 | |
|---|---|
| System | 电脑自带的语音：Linux 上是 speech-dispatcher，macOS 的声音（AVSpeechSynthesizer，包括在 系统设置 → 辅助功能 → 朗读内容 里下载的增强版、高级版声音），Windows 的声音（WinRT）。不另选时用它。 |
| System, by a program | macOS 和 Windows：同样的语音，用 `say`，或用 PowerShell 和 Windows 较旧的 SAPI 声音。 |
| Piper | 自然的声音，离线。安装 [Piper](https://github.com/OHF-Voice/piper1-gpl)，把声音（每个是一个 `.onnx` 和它的 `.onnx.json`）下载到一个文件夹，在设置里填这个文件夹。 |
| Azure Speech | 在线，用你自己的 Azure Speech 资源的 key 和区域。 |
| OpenAI or alike | 在线，用你自己的 key；API 地址、模型、声音可以改，用于 API 相同的其他服务或自己的服务器（如 Kokoro）。 |
| Browser | 窗口的 Web Speech API，有声音时可用。 |

在播放器的齿轮里设置。key 只存在这台电脑上、应用的数据文件夹里，不进工作区。用在线引擎时，朗读的文字会发给该服务。Piper 和在线引擎生成的音频存在缓存里，同一句再读不再生成；*Clear the audio made* 清除它们。
