# 阅读器

#手册#

阅读器是 mdSilo 的输入端。支持阅读、标注，并把标注保存为普通笔记，汇入你其余的知识库。

支持的格式：**EPUB、PDF、MOBI、AZW/AZW3、FB2、CBZ**（漫画）。TXT、Markdown、HTML 和 ZIP 文件在导入时会转换成 EPUB，你的原文件不会被改动。

## Library

用侧边菜单的书架图标打开（`Ctrl/Cmd + Shift + L`），列出工作区里所有的书。

- **Add books**：把书文件拖进窗口，或用 *Add books*。网页版里书存在浏览器中；桌面版会复制到 `reading/`。
- **Add folder**：导入一个文件夹及其子文件夹里的所有书，可以选格式。
- **网格或列表**：网格显示封面，列表显示作者、丛书和简介。
- **搜索**支持纯文本和正则，匹配书名、作者、格式、分组、状态、丛书、主题和简介。
- **分组**：把一本书拖到另一本书上建组，拖到组上移进去，拖到面包屑上移到上一层。分组可以嵌套（`Fiction/Classics`）。也可以按作者、丛书、格式或状态分组。
- **状态**：给书标 *Todo*、*Doing*、*Done*，或你自己的标记。
- **详情**：编辑元数据（书名、作者、丛书、语言……）、设置分组和状态、复制指向它的链接、打开它的批注。

书是按内容识别的（部分 MD5 哈希），所以改名或移动过的书，在每台设备上仍是同一本书。

:::info
**同步，逐本选择。** 书可能很大，所以默认*不*随 git 同步。每本书、每个分组都有同步开关；批注和阅读进度总是同步的。见 [[9 同步与发布|同步与发布]]。
:::

## 阅读

打开一本书，页面占满窗口。鼠标移到上下边缘，或点击页面中间，就会出现工具栏。

- **翻页**：点页面左侧或右侧，用方向键、鼠标滚轮，或底部的滑块。点中间显示或隐藏工具栏。
- **顶栏**：回到 Library、目录和笔记、书签、复制本页链接、并排阅读、*Font and layout*。
- **底栏**：阅读历史的后退和前进、上一章和下一章、进度滑块，以及全书剩余时间。
- **目录和笔记**（侧面板）：目录、你的批注、书内搜索，以及 **Links** 页。
- **字体和布局**：字体、字号、间距、页边距、页面颜色（跟随应用、白、米黄、灰、深色）、翻页或滚动、动画、页眉页脚显示什么、图片选项和代码高亮。
- 点击页面里的**图片**或**表格**可以放大查看。脚注会在小弹窗里打开，而不是跳走。
- 你读到哪里、读了多久，都按书保存，并汇入 [[8 洞察|洞察]] 里的热力图。

## 高亮和笔记

选中文字，上方会出现工具栏：

| 操作 | 作用 |
|------|------|
| Copy | 复制文字 |
| Highlight | 标记文字；可选样式（高亮、下划线、波浪线）和颜色 |
| Note | 给高亮写一条 Markdown 笔记 |
| Search | 在书里搜索选中的内容 |
| Dictionary | 查词（最多三个词），用 Wiktionary，可加入生词本 |
| Wikipedia | 选中内容的摘要 |
| Translate | 翻译成设置里选定的语言 |
| Read aloud | 从选区开始朗读 |
| Copy quote | 把文字复制成 Markdown 引文，带回到这一页的链接 |
| Copy link | 指向书中这个位置的链接 |
| **New issue of it** | 用选中内容建一个 issue，见 [[7 Issue|Issue]] |

你所有的标注都写进**书旁边的一个 Markdown 文件**：`Foo.epub` 对应 `Foo.epub.md`。它是一篇普通笔记：每章一个标题，每条高亮是一段引文，你的笔记写在下面。你可以编辑它、搜索它、用 `[[ ]]` 链接它，也能在 Graph 里看到它。

```markdown
## Chapter I

<!-- mdsilo:note {"id":"…","cfi":"epubcfi(…)","color":"yellow"} -->
> Alice was beginning to get very tired of sitting by her sister on the bank

开篇。整本书是一场关于好奇心的梦。
```

注释里记着位置，这样高亮才能重新画回页面上；编辑器会原样保留它。点页面上的高亮，会显示它的笔记和链接到它的 issue。

## 从书走向工作区的其余部分

- 在任何笔记里用 `{{` **链接到书**。链接到某处高亮，就能跳到那句话。见 [[4 链接|链接]]。
- 侧面板的 **Links** 页列出指向这本书的笔记和 issue：它的反向链接。
- **New issue of it**：引文和回链变成一个 issue。批注列表里每条高亮都有同样的按钮。
- Graph 把书画成一个节点，连着它的批注笔记，以及每篇链接它的笔记。

拿 {{Alice's Adventures in Wonderland}} 试一试：它在你的 Library 里，第一章已经有一处高亮。加上你自己的高亮，把它做成 issue，再去看 Graph。

## 并排阅读

顶栏的 *Parallel reading* 会在右侧打开第二本书。两本书可以独自翻页，都可以高亮和写笔记。用它来对照译本和原文，或正文和注疏。同一本书不能在两栏同时打开。

## 词典、生词本和翻译

双击一个词，或选 *Dictionary*。弹窗显示 Wiktionary 的释义（优先书的语言）。**Add to vocabulary** 会把这个词连同释义、所在的句子和指向书的链接存起来。**Vocabulary** 页（在 Library 页头）可以用卡片、网格或批量方式复习。

## 朗读

*Read aloud* 按钮会从选择的文字处或当前页开始朗读，逐句高亮，并自动进入下一章。控制都在播放器里（侧边菜单的耳机图标）：暂停、上一段/下一段、语速、引擎和声音。可选的声音是书的语言的那些。

引擎：

| 引擎 | |
|---|---|
| System | 电脑自带的语音：Linux 上是 speech-dispatcher，macOS 的声音（AVSpeechSynthesizer，包括在 系统设置 → 辅助功能 → 朗读内容 里下载的增强版、高级版声音），Windows 的声音（WinRT）。不另选时用它。 |
| System, by a program | macOS 和 Windows：同样的语音，用 `say`，或用 PowerShell 和 Windows 较旧的 SAPI 声音。 |
| Piper | 自然的声音，离线。安装 [Piper](https://github.com/OHF-Voice/piper1-gpl)，把声音（每个是一个 `.onnx` 和它的 `.onnx.json`）下载到一个文件夹，在设置里填这个文件夹。 |
| Azure Speech | 在线，用你自己的 Azure Speech 资源的 key 和区域。 |
| OpenAI or alike | 在线，用你自己的 key；API 地址、模型、声音可以改，用于 API 相同的其他服务或自己的服务器（如 Kokoro）。 |
| Browser | 窗口的 Web Speech API，有声音时可用。 |

在播放器的齿轮里设置。key 只存在这台电脑上、应用的数据文件夹里，不进工作区。用在线引擎时，朗读的文字会发给该服务。Piper 和在线引擎生成的音频存在缓存里，同一句再读不再生成；*Clear the audio made* 清除它们。
