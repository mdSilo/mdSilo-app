# 同步与发布

#手册#

工作区就是一个装着纯文本文件的文件夹，所以它可以像代码一样放进 **git 仓库**。mdSilo 能把这个仓库和 GitHub、Gitea、GitLab 或任何 git 托管同步，还能把你选的笔记做成 GitHub Pages 上的**静态网站**。这两项都在桌面版里；网页版的工作区存在浏览器中，请用 **File Menu > Backup**（见 [[参考]]）。

## 用 git 同步

### 设置一次

1. 在 git 托管上建一个**空的私有仓库**，例如 GitHub 上的 `notes`。
2. 创建一个能写入它的**个人访问令牌**（token）。GitHub 上：*Settings > Developer settings > Fine-grained tokens*，授权这个仓库，权限选 **Contents: Read and write**。
3. 在 mdSilo 里点 **Sync**（侧边菜单底部、齿轮上面的循环箭头），填写：
   - **Repository URL**：HTTPS 地址，例如 `https://github.com/me/notes.git`；
   - **Token**；
   - **User name**：托管要求和 token 一起填用户名时才需要；
   - **Author(optional)** 和 **Email(optional)**：提交上显示的名字，可不填。不填就用你的 git 配置，没有则是 *mdSilo*。
4. **Save**，然后 **Sync now**。

:::info
token 保存在这台设备的应用数据里，**不在工作区里**，也不进仓库，所以不会跟着笔记走。目前只支持 HTTPS 地址，不支持 SSH（`git@...`）。
:::

### 同步做了什么

一次同步会把你的改动存成一个提交，取回其它设备的改动，再把你的发出去：*提交、拉取、推送*，一键完成。之后对话框会显示收到了多少个文件、你的改动是否已发出、时间。

- **会同步的**：笔记、书的批注和阅读进度、生词本、issue、项目、订阅。
- **不同步的**：`.mdsilo/local/`（这台设备的搜索索引和缓存），以及**书文件**，除非你在书库里为这本书打开同步（见 [[5 阅读器|阅读器]]）。之后再关掉，其它设备上的书仍会保留。
- **新设备**：打开一个空文件夹，设置同一个仓库，**Sync now**，所有内容都会下来。如果仓库的主分支叫 `master`（或别的名字），新工作区会跟着用它。

### 自动同步

**Sync now** 下面的 **Automatic sync** 可以替你同步：

- **Every**：每 5、15、30 分钟或每小时一次；
- **When the app closes**：关闭窗口或从托盘 Quit 时。应用会等同步完成，最多 30 秒，然后照常关闭。

每次同步前会先保存还没保存的编辑。同步失败（没网、token 不对）时，Sync 按钮上会出现红点，打开就能看到原因。

### 两台设备改了同一处

不同的笔记、同一篇笔记的不同地方，会自动合并。两台设备改了同一篇笔记的同一些行时，**什么都不会丢**：

- 笔记里保留远程的版本；
- 你这边的版本另存在旁边，名为 `笔记 (conflict 2026-10-29 1530).md`。

对话框会列出两者，点开看看，留下想要的，删掉副本即可。`.mdsilo/` 里的应用数据（书库、生词本、issue）则按字段合并：一台设备加的书、另一台设备改的分组，都会保留。

## 发布网站

**File Menu > Publish** 把你选的笔记做成一个网站：普通的 HTML 页面，带着你的链接、反向链接、图谱和搜索，有亮色和暗色。不需要安装任何东西，网站也不从别的服务器加载东西。

### 公开哪些内容

由你决定，缺省是什么都没勾选：

- **Folders**：勾选要发布笔记的文件夹，子文件夹随之一起发布。
- 单篇笔记可以在 front matter 里写 `publish: false` 排除自己，或写 `publish: true` 从任何文件夹加入：

```markdown
---
publish: false
---
```

- **With**：网站上还要显示什么：**Backlinks**（反向链接）、**Graph**（图谱）、**Tag pages**（标签页）、**Journals**（日记，放在首页）、**Book annotations**（书的高亮和笔记，书本身永远不会发布）、**Issues**（含时间线、里程碑和项目看板）。issue 可以再勾选标签，例如 `public`，只发布带这些标签的 issue。
- **Draw**：**Math**（公式）、**Mermaid**、**ECharts**、**SMILES**（化学结构）在发布时画好，读者不需要网站加载任何库就能看到公式、图表和化学结构。关掉则显示源码。

:::warning
**指向未发布笔记的链接显示为纯文本**：读者只看得到标题，看不到内容。注释（`<!-- -->`）和 front matter 不会出现在任何页面上。即便如此，发布前请检查你勾选的内容：发布的网站是公开的。
:::

这些选择保存在 `.mdsilo/publish.json` 里，所以每台设备发布的是同一个网站。

### 发布到 GitHub Pages

设置好同步后，**Publish to GitHub Pages** 会生成网站，并用同一个 token 推送到同一个仓库的 `gh-pages` 分支。存笔记的分支不受影响，网站分支只保留最新的一版。

第一次需要在仓库里打开网站：*Settings > Pages > Deploy from a branch > `gh-pages`*。对话框会显示网址，例如 `https://me.github.io/notes/`，可能要等一分钟才能访问。

:::tip
私有仓库让笔记保持私密，网站则是公开的。GitHub 的私有仓库使用 Pages 需要付费计划；否则可以用一个只放网站的公开仓库，或者 **Export to folder…** 导出后放到任何能提供静态文件的地方。
:::

### 导出到文件夹

**Export to folder…** 把同样的网站存放到你选择的文件夹里。用浏览器打开其中的 `index.html` 检查，或上传到任何静态托管网站发布（Netlify、Cloudflare Pages、Vercel、你自己的服务器）。
