## 快捷键

`Mod` 在 Windows 和 Linux 上是 `Ctrl`，在 macOS 上是 `⌘`。

### 应用

| 快捷键 | 操作 |
|--------|------|
| `Mod + N` | 查找或新建笔记 |
| `Alt + X` | 显示或隐藏侧栏 |
| `Mod + Shift + D` | 侧栏：Silo（文件树） |
| `Mod + Shift + F` | 侧栏：Search |
| `Mod + Shift + H` | 侧栏：Hashtag |
| `Mod + Shift + P` | 侧栏：Playlist |
| `Mod + Shift + R` | 视图：订阅 |
| `Mod + Shift + L` | 视图：Library |
| `Mod + Shift + I` | 视图：Issues |
| `Mod + Shift + T` | 视图：Tasks |
| `Mod + Shift + K` | 视图：Projects |
| `Mod + Shift + C` | 视图：Chronicle |
| `Mod + Shift + G` | 视图：Graph |

## 搜索

侧栏的 **Search** 页对工作区做全文搜索：笔记、书的批注，以及书的正文（桌面版里书库中的书不用打开就能搜到，web 版是打开过的书；PDF、漫画不在其中）。结果会显示词出现的位置。索引在后台建立，编辑时增量更新；中文等不用空格分词的语言会按词切分。

## 设置

侧边菜单底部的齿轮打开全局设置：

- **Language**：界面语言，English、Español、简体中文或繁體中文，或跟随系统。
- **Theme**：mdSilo 亮色和暗色，或跟随系统，另有八个内置主题，以及你自己做的主题。主题编辑器设置每个颜色和它上面内容的颜色（内容在颜色上看不清、对比度低于 4.5:1 时会提示），方框、输入框、选择控件的圆角和边框宽度；可导入、复制 daisyUI 主题的 CSS。
- **Dictionaries**：查词用哪些词典、顺序、你加的网站和词典文件（见 [[5 阅读器|阅读器]]）。
- **Fonts**：导入字体文件，或按名字添加已安装的字体；它们会出现在编辑器和阅读器的字体列表里。应用（不含 web 版）的字体列表里还会列出设备上已安装的字体（*System*）。
- **Sync with workspace**（主题、字体、插件）：放在工作区里随之同步，或只留在这台设备上（见 [[9 同步与发布|同步与发布]]）。
- **Side menu orientation**：自动、竖排或横排。自动：在侧边，但在手机上侧边菜单收进每页菜单栏开头的 Logo 里，点它打开视图、文件菜单、同步和设置。
- **Open on startup**：上次的文件夹、固定的文件夹或不打开；以及 **view on startup**，例如 Library 或这个文件夹里上次读的书。
- **Check for Updates on Startup**（桌面版）：见下文「桌面版」。
- **Plugins**：*Manage Plugins*，见下文「插件」。

各个区域的设置放在用到它的地方：编辑器的在笔记的齿轮里（字体、字号、行高、字重、拼写检查、附件文件夹），阅读器的在顶栏的 *Font and layout*，订阅的在 *Manage Channels and Settings*。

## 网页版

和这套手册在同一个地址的网页版，就是同一个应用。区别：

- 你的工作区**存在浏览器里**（IndexedDB），不会发送给任何服务器。
- 用 **Open Folder** 从设备导入文件夹，用笔记的选项菜单导出；文件由浏览器下载。
- 订阅要走 CORS 代理，见 [[6 订阅|订阅]]。
- 没有原生的文件监听，没有 git 同步和发布；书很多的话，[桌面版](https://github.com/mdSilo/mdSilo-app/releases)更合适。
- **可以装成应用**，手机上也行：Logo 菜单 > **Install App**（Chrome、Edge、Android），或在 iPhone、iPad 的 Safari 里：分享 > **添加到主屏幕**。之后它在自己的窗口里打开，离线也能用；订阅和书目仍需联网。手机上侧边菜单收进每页菜单栏开头的 Logo 下拉里，Feed 一次显示一栏。有新版本时会提示重新载入。

:::warning
**请备份。** 清除浏览器的站点数据会删掉你的笔记。用 **File Menu**（侧边菜单底部的文件夹图标）> **Backup** 把全部内容下载为 zip，用 **File Menu > Restore Backup** 恢复：相同路径的文件被替换，其他文件保留。有改动又 14 天没备份时，应用会提醒你。

**Settings > Storage** 显示工作区占了多少空间，以及浏览器空间不足时会不会保留它。如果不会，**Keep My Data** 请浏览器保留；装成应用也有帮助，在 iPhone 和 iPad 上，这样 Safari 才不会清掉 7 天没访问的网站数据。这里还能备份、备份到电脑上的文件夹（Chrome、Edge）、恢复，以及 **Clear All Data**。存储满了时改动存不下，提示里会写已用多少。
:::

:::info
**清除示例。** 网页版首次打开时附带的手册、示例书和示例 issue，可以用 **File Menu**（侧边菜单底部的文件夹图标）里的 **Remove demo** 一键删除。你自己建的笔记、issue 和书不受影响。
:::

## 桌面版

支持 Windows、macOS 和 Linux。你的工作区就是真实的文件夹：可以用自带的 git 同步（见 [[9 同步与发布|同步与发布]]），或用 Dropbox、Syncthing 同步，也可以用别的编辑器改文件，改动会出现在 mdSilo 里。

**更新。** 启动时应用会向 GitHub 查询有没有新版本，有就提示安装并重启；在设置里关掉 *Check for Updates on Startup* 就不再查，随时可以用 *About → Check for Updates* 手动检查。下载的安装包带签名，应用安装前会校验。安装应用、在终端里更新，见仓库的 README。

## 插件

插件给 mdSilo 添加功能：某种文件的查看器（比如把 `.csv` 显示成表格）、侧边菜单 Plugins 菜单里的整个工作区的视图、阅读器和编辑器里对选中文字的操作、命令、和 WYSIWYG/Markdown/MindMap 并列的笔记模式、阅读器的面板，以及由插件来画的代码块（编辑器和发布的网站里都有）。

- **安装**：在 *Settings → Manage Plugins*（或侧边菜单的 Plugins 按钮）里选 *Install Folder* 或 *Install .zip*。然后启用它，并选择允许它做什么：读写它打开的文件、读写笔记、读书和 issue、读正在看的书、联网。可以只给它要的一部分。
- **默认在沙盒里**：插件在自己的 frame 里运行，只能做你允许的事。*trusted* 插件在应用内部运行，能做更深的改动，安装时要你确认。
- **Update** 从原来的位置重新安装插件；**Develop** 监视一个文件夹，文件变了就重新载入插件。
- 插件放在这台设备上，或者打开 *Sync with workspace* 放进工作区；同步过来的插件不会因同步而被启用。
- 一个部分兼容的层能让一些 Obsidian 插件运行。

可以试用的示例和插件的写法，在仓库的 `examples/plugins` 里。

## 永远是纯文件

| 内容 | 位置 | 格式 |
|------|------|------|
| 笔记 | `writing/**/*.md` | Markdown |
| 书的批注 | `reading/Foo.epub.md` | 带注释的 Markdown |
| 剪藏的文章 | `reading/clips/*.md` | Markdown |
| 书库 | `.mdsilo/books.json` | JSON |
| 阅读进度 | `.mdsilo/books/<id>.json` | JSON |
| Issue、标签、项目 | `.mdsilo/` | JSON |
| 订阅 | `.mdsilo/feeds.json` | JSON |
| 发布的选择 | `.mdsilo/publish.json` | JSON |
| 生词本 | `.mdsilo/vocabulary.json` | JSON |
| 导入的词典 | `.mdsilo/dictionaries.json`，文件在 `.mdsilo/dictionaries/<id>/` | JSON、MDict |
