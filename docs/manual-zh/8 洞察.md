# 洞察

#手册#

读、想、写了一阵之后，工作区里有些关于你的事，是你自己都没留意到的。洞察视图把它们显示出来。

## Graph

`Ctrl/Cmd + Shift + G`，或侧边菜单的图标。

Graph 把你的工作区画成一张网：

- **笔记**是圆形节点，由 `[[wiki 链接]]` 相连。链接多的笔记画得更大。
- **书**是竖放的小书（带书脊），连着它的批注笔记，以及每一篇用 `{{ }}` 链接它的笔记。书和它的批注之间的线是实心加粗的。
- **Issue** 是像 GitHub 那样的圆环：open 是绿色，closed 是灰色，连着提到它们的笔记，和它们指向的笔记。
- **标签**把带有同一标签的笔记连在一起。

拖动节点可以拽动整张网，滚轮缩放，拖动背景平移，点节点打开它。孤立的笔记会飘离主体：这是发现还没连上的想法的好办法。

> 单独读一本书，只得到一个节点。带着高亮读它，再把高亮链接到笔记和 issue，得到的是一个星图。

## Chronicle

`Ctrl/Cmd + Shift + C`，或日历图标。

- **Journals**：每天一篇笔记。*Today* 打开（或创建）`writing/daily/<日期>.md`。所有日记都列在 **Journals** 下。
- **活动热力图**：类似 GitHub 的日历，显示你每天做了多少。写作按对笔记的编辑计数。读过书之后，会出现 **All**、**Writing**、**Reading** 的切换，悬停时两项数字都显示。阅读按阅读器测得的时间，每 15 分钟计算一次。
- **时间线**：热力图下方，笔记按最后修改的日期列出。点热力图上的格子可以跳到那一天。

Chronicle 回答“上周二我做了什么？”和“我是不是冷落了阅读？”，而你不用做任何记账。

## Hashtag

侧栏的 **Hashtag** 页是你的主题词汇表。标签打得越多，它越能说明你的注意力去了哪里。

## 反向链接和提及

每篇笔记的底部：链接到它的笔记，以及提到它的标题但没有链接的笔记。适合发现一个隐藏的主题结构。见 [[4 链接|链接]]。
